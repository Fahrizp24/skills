# skills

Skill agen untuk menulis dan mengaudit karya ilmiah serta proposal berbahasa Indonesia: bukti dulu, sitasi dapat diperiksa, pola AI-slop dibuang.

Tidak menjamin lolos AI detector. Tujuannya tulisan yang jujur, spesifik, dan dapat dipertanggungjawabkan penulis.

## Instal

```bash
npx skills add Fahrizp24/skills --skill penulisan-ilmiah-indonesia
```
